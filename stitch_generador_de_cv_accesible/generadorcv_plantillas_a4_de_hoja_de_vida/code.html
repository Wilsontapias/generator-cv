Reglas Estrictas @media print (A4)

Implementación certificada en CSS para evitar saltos de página indebidos y forzar la fidelidad de colores del navegador: 

@page {
  size: A4 portrait;
  margin: 0mm; /* El padding interno de 15mm controla los márgenes */
}

@media print {
  body {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
    background: #ffffff !important;
  }

  .no-print {
    display: none !important;
  }

  /* Evitar cortes indeseados en experiencias laborales */
  .page-break-avoid {
    break-inside: avoid !important;
    page-break-inside: avoid !important;
  }
}
